## Как добавить ролик в кейс

В каждом кейсе с видео (Авито, МегаФон, Кидз) уже стоит «постер» с кнопкой play и подписью «видео — скоро». Файл с роликом подгружается только в момент, когда кто-то нажимает на эту кнопку — до клика 0 трафика, страница не тормозит.

**Способ 1 — положить файл рядом (рекомендую для коротких роликов).**

1. Подготовьте `.mp4` весом ~5–15 МБ (как — ниже).
2. Положите в нужную папку под именем `video.mp4`. Например, для Авито: `assets/cases/avito/video.mp4`.
3. Готово — ничего больше делать не нужно. Откройте сайт, нажмите play на этом кейсе.

**Способ 2 — embed-ссылка (YouTube / Vimeo / Cloudflare Stream).**

В `index.html` найдите нужный блок плеера. Сейчас там:

```html
<div class="player has-poster" data-video-src="assets/cases/avito/video.mp4">
```

Замените на:

```html
<div class="player has-poster" data-video-embed="https://vimeo.com/123456789">
```

Поддерживаются ссылки YouTube, Vimeo, Cloudflare Stream (других можно добавить — скажите).

## Как подготовить видео, чтобы быстро открывалось

Цель: один ролик ~5–15 МБ при качестве 1080p. Это критично для мобильных и медленного интернета.

- **Самый простой способ** — программа [HandBrake](https://handbrake.fr/) (бесплатная, есть для Windows и Mac).
  1. Открыли исходник
  2. Preset: «Web → Vimeo YouTube HQ 1080p60»
  3. Quality (вкладка Video): RF 24–26 (чем больше — тем меньше файл)
  4. Save As: `video.mp4`
- **Если умеете в командную строку** — ffmpeg:
  ```
  ffmpeg -i input.mov -vcodec libx264 -crf 26 -preset slow -movflags +faststart -vf "scale='min(1920,iw)':-2" -acodec aac -b:a 128k video.mp4
  ```
  Ключевой флаг — `-movflags +faststart`: видео начинает играть до того, как полностью скачается.

Цель по весу:
- ролик 15–30 сек → 3–7 МБ
- ролик 30–60 сек → 6–15 МБ
- ролик 1–2 мин → 15–30 МБ

Если ролик длиннее 2 минут или итоговый файл больше 30 МБ — лучше способ 2 (Vimeo / Cloudflare Stream): они автоматически отдают разное качество разным устройствам, и мобильный пользователь не будет ждать.
